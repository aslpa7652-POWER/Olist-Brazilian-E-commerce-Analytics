 | 🔗# Olist Brazilian E-Commerce Analytics

End-to-end data analytics project on Olist's Brazilian e-commerce marketplace data — from raw multi-table CSVs to a business-ready Power BI dashboard.

## 🎯 Business Objective

Olist connects small Brazilian businesses to customers nationwide through a single marketplace. This project analyzes ~112K order-line records (2016–2018) to answer:

* Where is revenue coming from, and how is it growing?
* Which product categories and states drive the most value?
* How does delivery speed affect customer satisfaction?
* Where should the business focus to grow profitably?

## 🛠️ Tech Stack

* **Python** (Pandas, NumPy, Seaborn, Matplotlib) — data cleaning, merging 7 raw tables, feature engineering
* **MySQL** — 36+ business queries including CTEs and window functions
* **Power BI** — interactive dashboard with KPIs, slicers, and drill-downs

## 📊 Key Results

| Metric                  |     Value |
| ----------------------- | --------: |
| Total Revenue           |  R$20.19M |
| Total Profit (est.)     |   R$2.71M |
| Average Order Value     |  R$206.18 |
| Average Customer Rating |  4.03 / 5 |
| 2018 YoY Revenue Growth |   +21.15% |
| Average Delivery Time   | 12.4 days |

## 💡 Key Insights

1. **Bed/Bath/Table** and **Health & Beauty** are the top revenue categories.
2. **São Paulo (SP)** alone accounts for ~42% of all customers.
3. **November 2017** was the best-performing month (Black Friday effect).
4. **78% of revenue** happens on weekdays vs. 22% on weekends.
5. **Delivery speed is associated with review scores** — 5-star orders arrive ~8 days faster on average than 1-star orders.
